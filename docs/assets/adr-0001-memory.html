Memory & retrieval · ADR-0001

记忆不是一层，是三层各查各的

左列四个梯级从上往下走：三个入口共用一个会话层，会话层去查一次长期记忆，查之前先过一道检索路由—— 能键匹配就别做语义。多数人把“记忆”当成一个向量库，但对账场景里真正需要向量检索的只有最后那张表。

Three doors, one memory

三档入口，一套记忆

L0 表单、L1 内置会话、L2 宿主，共用同一份工具清单和同一套审批闸门。分档只影响「谁在编排」，不影响「能做什么」。

Structured first

能键匹配就别做语义

对账里的记忆九成是结构化事实：口径、维度、容差、cause_key。它们用 SQL 精确查，比向量更准、更快、还能解释为什么命中。

Who writes wins

写回有主，会话不是签字

人确认写回置信度 0.9，模型自述 0.5。聊天里说过「我同意」不等于审批——审批只认确认码和内容哈希。
